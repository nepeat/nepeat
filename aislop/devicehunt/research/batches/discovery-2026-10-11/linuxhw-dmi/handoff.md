Deviation (now only in the NOT-FOR-IMPORT leads file): when every System Information pair in a dir is a placeholder/empty (`O.E.M`, `To be filled by O.E.M.`, `OEM`, `0000`, empty) or product == manufacturer (`DEPO Computers`), the brief-compliant result is no identity for that dir. 74 such dirs (72 Foxconn boards, Quanta XV1 whose System Manufacturer is VIZIO, Quanta 2AF5 whose is Hewlett-Packard) would otherwise be silently lost, so they are offered as `motherboard` identities from the Base Board manufacturer/product with fact `dmi_identity_basis` = `base board ...`; the raw System strings are still facts. Template strings (`Base Board Product Name`, `Type2 - Board Product Name1`) are never identifiers.

One value omitted by a value rule (`dmi_value_omitted` fact): Hyve Rigel-HS9216 baseboard Version `5411C4050059` (12 hex characters, MAC/serial-like), rule "12+ hex chars in a *_version field". Upstream's retained dump contents (hashed serial lines, OEM strings, per-unit numbers elsewhere in the dumps) are in the raw captures but unextracted. HWID file names (12-hex upstream probe hashes) appear in citations/paths only; they are upstream-published probe IDs, not serials.
