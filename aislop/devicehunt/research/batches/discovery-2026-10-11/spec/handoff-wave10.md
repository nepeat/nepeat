## How the HTML is parsed and mapped
Each page is parsed into `<tr>` rows of cell texts (whitespace normalised). Header rows give title line, `Tested by`, `Test Sponsor`, `Hardware Availability`, and the max-jOPS / critical-jOPS cell. The `Hardware hw_1` block (rows until the next section title) gives Vendor, Name, Model, Form Factor, CPU Name/Characteristics/Frequency, Nodes/Systems/Chips/Cores/Threads, Memory Amount, `# and size of DIMM(s)`, Memory Details, `Power Supply Quantity and Rating (W)`, Cabinet/Housing/Enclosure, Shared Description/Comment, Available. Fields printed `None` are omitted. Only hw_1 is extracted. Exactly one page lists a second hardware block: `jbb2015-20160705-00111` (Oracle `SPARC S7-2`, Distributed) also has `Hardware hw_2` = `Sun Server X4-2L` (Vendor Oracle Corporation), referenced under a separate configuration; its coverage now says hw_2 is a different system, not extracted and not attributed to the identity (the other 148 pages have one block). Each evidence entry has `literal_quote` = exact cell text (for header/jOPS facts the exact substring of the cell) and a `locator` (e.g. `SUT Description > Hardware hw_1 > Form Factor`, `page header > Test Sponsor`) instead of a line number.
Identity (revision-3 rules adapted to jbb field names): jbb pages have no "Hardware Vendor" header line, so brand = the **`Vendor` field of Hardware hw_1** (canonical target name only for reviewed TARGETS aliases, else as printed); model = hw_1 `Name` minus a trailing CPU/config parenthetical (none occurred; 0 stripped); full name kept as `spec_system_name` identifier and fact; role `brand` when `Test Sponsor` equals that Vendor, else `reported_system_vendor` (jbb "Tested by" is a fact only). The page title line is `<vendor> <system>` for most pages but differs for some (`Inspur Corporation NF5280M6` with Name `Inspur NF5280M6`; `Quanta Cloud Technology, QuantaGrid D43K-1U`; `Inspur PowerSystem FP5280G2` with Vendor `Inspur PowerSystem Corporation`): identity uses the hw_1 fields and the coverage says when the title differs.
