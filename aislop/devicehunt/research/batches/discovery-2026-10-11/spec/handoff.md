## Identities and facts (convention)
- One source per result: `spec-<result file stem>` e.g. `spec-power_ssj2008-20230522-01258`, `spec-cpu2017-20250812-49369`; url = the `.txt`; tier `vendor` (vendor-submitted full disclosure published by SPEC; license text keeps SPEC/submitter rights). Coverage states the capture sha256, wrapped-line joining and the no-role caveat.
- One device row per result; identity = (brand = result's Hardware Vendor string exactly, model = system name exactly); identifier `spec_system_name`; kind `server`. Repeated systems merge in the catalog (237 records -> 205 devices; 18 devices have >1 record).
  - SPECpower: `Hardware Vendor:` and `Model:` are separate printed fields. CPU2017: the text prints "<vendor> <system>" on the title line(s); split using the SPEC index `hw_model` (the printed block must equal vendor + " " + that exact string; all 180 did). In some results the vendor is already on its own line (e.g. "Quanta Cloud Technology" / "QuantaGrid S44NL-1U (2.25 GHz,AMD EPYC 9754)").
  - Model strings keep the printed CPU/clock suffix (e.g. `D55Q-2U (Intel Xeon 6780E)`, `NF290D2 (2.5 GHz, Intel Xeon Processor L5420)`), which is what makes some names distinct.
- Affiliation convention: only `[[<Hardware Vendor string>, "brand"]]` (the Edge-Core curated precedent: vendor brand -> brand affiliation). No manufacturer/OEM/ODM/operator/documentation_vendor roles; Test Sponsor / Tested By are plain facts (they differ, e.g. Hardware Vendor `Quanta Cloud Technology` with sponsor `Quanta Computer Inc.`; `FOXCONN (FII)` tested by Infobell). Oracle-precedent `documentation_vendor` was deliberately NOT added. Brand strings are never normalized or merged (Quanta Cloud Technology vs Quanta Computer Inc., the three Inspur strings, `IEIT Systems Co., Ltd.`, `Sun Microsystems` vs `Sun Microsystems, Inc.` vs `Oracle Corporation` all stay separate; IEIT is not mapped to Inspur). Decision for integrator: whether brand-only affiliations from a benchmark submission are acceptable.
- Facts (names = `spec_` + result-file label; every fact has an `evidence` entry with line number(s), quote, url, capture sha256; 3905/3905 quotes re-found in the captured text):
  - SPECpower (57): `spec_benchmark`, `spec_result_headline` (`SPECpower_ssj2008 = 16,545 overall ssj_ops/watt`), `spec_hardware_vendor`, `spec_model`, `spec_test_sponsor`, `spec_tested_by`, `spec_hardware_availability`, `spec_system_designation`, `spec_test_method`, `spec_number_of_identical_nodes`, `spec_form_factor`, `spec_cpu_name`, `spec_cpu_characteristics`, `spec_cpus_enabled`, `spec_cpus_orderable`, `spec_hardware_threads`, `spec_memory_amount_gb`, `spec_number_and_size_of_dimm`, `spec_memory_details`, `spec_power_supply_quantity_and_rating_w`, `spec_power_supply_details`, `spec_result_url`.
