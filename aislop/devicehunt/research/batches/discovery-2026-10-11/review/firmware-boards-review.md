## Findings

### Must-fix
None.

### Should-fix
S1. Name the ROM fact as a select. Rename `coreboot_kconfig_romsize` to something like `coreboot_kconfig_romsize_select` (value text is already the literal `select` token plus cite). Reason: on a buyer-facing row a bare "romsize" key reads as a hardware flash size; the file has no printed ROM size (board_info.txt has none on any of the 8 boards). In the handoff replace "ROM size select 32768 KB" style prose by the literal token or "Kconfig select BOARD_ROMSIZE_KB_32768". Cheap, and consistent with the "derived/not printed" labelling the bmc review asked for.
S2. U-Boot yosemite4: drop it (or at minimum fix the kind). Reasons: (a) selected only on a name token whose link to Meta/OpenBMC "yosemite4" is outside knowledge, not anything in the file (grep: no "facebook"/"bmc" in the dts); (b) the source brief is board dirs, U-Boot has zero, and the handoff itself offers to drop it; (c) device `kind` is "BMC bootloader device tree" but the dts says neither BMC nor bootloader role (model "Nuvoton npcm845 yosemite4", Copyright Nuvoton, root compatible `nuvoton,npcm845`), so "BMC" is an unstated inference; (d) the file is orphaned (no yosemite line in arch/arm/dts/Makefile, no defconfig), and the pincfg dtsi it includes is not captured, so it is a thin stub. Keeping would be harmless data-wise (facts are accurate: model :11, compatible :12, Makefile :1080 verified). If kept, change kind to "device tree source" and keep the existing "label, no mapping" coverage text. Dropping removes 1 source/device/record/identifier and 7 facts (counts become 8 / 157); record the negative result (zero target board dirs in U-Boot) in the handoff only.
S3. Handoff wording on leads. State FBG-1701 and transformers as exact-string coincidences needing separate evidence (name agreement only; different kinds, no shared source), and note that the `transformers` OpenBMC identity is a BMC firmware machine whereas the coreboot one is host firmware for an Inventec-labelled board; both are Inventec-labelled by directory name only. Do not use either lead to attach a company role or merge.
