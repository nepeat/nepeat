## results

- **S4** ([handoff](batches/ops-2026-10-10/s4/handoff.md)). `CampaignState.reconcile_clock(account,
  archive=, decision=)` re-baselines `start_mono`/`boot` (and moves `start_wall` earlier only when
  monotonic consumption exceeds wall elapsed). On the same boot, consumed = max(wall, monotonic), so
  remaining time never grows. After a boot change only wall time is evidence. It refuses healthy
  timing, stopped or untimed accounts, open reservations, wall time before the account start, and an
  empty decision. `reconcile_throttle(event, decision=)` appends a recovery event and never shortens
  the wall delay. `_eligible` is unchanged; `_eligible` stops are never persisted to
  `accounts.stopped`; `reservations.boot` is write-only. The `/proc`-less `_boot()` fallback is now
  per-process unique. Driver: `live_rra.py reconcile ACCOUNT --label L --decision D`.
- **queue baseline** ([handoff](batches/ops-2026-10-10/queue/handoff.md)). With a gated accepted
  manifest, the queue verifies the gate (`gate_inputs`) and takes each unit's baseline job and inputs
  from the accepted release. An excluded entry stays excluded, and a unit absent from an older release
  falls back to the path match. Releases emit the baseline job for non-accepted units plus optional
  `candidate_job`, which `gate_inputs` forbids importing. `check_release` rejects shared jobs. Schemas
  are unchanged, the promoted release still validates, and the projection canary is unchanged.
