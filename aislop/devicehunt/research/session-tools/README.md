# Archived one-off session helpers

188 transient research/import/audit scripts are preserved through the Inspur 2018 / Inventec enterprise hardware batch.
These are historical records, not an install procedure or a safe batch to rerun.
Some contain absolute old paths, hard-coded prior counts, network requests or
mutating imports. Read and adapt an individual script before running it.
Use the current `devicehunt` CLI and `scripts/` tools for normal work.
