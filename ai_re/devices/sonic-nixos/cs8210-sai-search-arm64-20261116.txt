## Reference facts gathered (useful for the next try)
  - isai.deb 7.0.1 (local copy, sha256 9ebc5cb3...) ships usr/lib/libifcs.so (x86-64, with debug_info, 474 MB, IFCS 0.16.0 string; sha256 below),
    libsai.so.1.0 (x86-64, stripped; contains IFCS version format strings and IVM77700 config), libmkaecp.so.1.0.0, mrvl_sdk_config.py.
    So the modern SAI is a thin layer over a separate libifcs ABI; the old 0.11.1 (202006) libsai.so.1.0 is one 86 MB x86-64 lib with IFCS linked in
    (ISAI_BUILD_VERSION=0:11:1). Both published SAI lines are x86-64 only.
  - The CS8210 arm64 libifcs (R3181-J0001-01_V0.1.7_Briggs_SDK, 37 MB, e_machine 0xb7) has the string
    "IFCS SDK version(%d:%d:%d) mismatch with driver version": SDK<->ipd version lock; an x86 SAI/IFCS would need a matching ipd (source is open, see above).
  - IFCS version bundled in each published SAI was not extracted (version is int triplets, not a plain string); only 0.16.0 appears in 7.0.1's libifcs.
