## system LED keeper (cs8210-leds monitor, journal of the cold boot)
blink-amber at 12 s ("fand in failsafe": fand's boot-time failsafe, see links-20261125.txt), green at 82 s.
Before this change the system LED field was 7 (0x20 = 0x7f, no vendor meaning: nothing set it under NixOS).

## port LEDs following link: not possible from the CPU
LED CPLDs 0x63/0x64 decode the ASIC's serial LED stream; the CPU can only force a whole CPLD (16 cages) to a test
colour (0x09 bit 0, colour 0x0a). The stream needs the vendor init lines the SAI does not run
(pci write led_cfg PIC_STREAM_MODE_F 1 / sck_rate_f 0x8, led_refresh_precliff 0x18eec2, led_refresh_cliff 0x020,
led_refresh_tmr_ctl ENABLE_F 1): sonic.md "LEDs".
