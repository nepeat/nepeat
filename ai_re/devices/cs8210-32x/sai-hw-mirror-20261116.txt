# CS8210-32X: mirror sessions and sFlow sampling on our SAI (sai-teralynx), chip runs 2026-11-16
# Same setup as sai-hw-qos-20261116.txt (qos-hw.json, traps.profile, lease "qos-mirror", cages 1 + 16 only).
# Copies are counted with port counters (IF_IN/OUT_UCAST_PKTS, IF_IN/OUT_OCTETS): in this build frames that
# flood or miss do not reach the CPU netdevs (only trapped / sampled ones do), so a copy is seen as Ethernet0
# ingress traffic. Mirror monitor port = Ethernet120, so copies go out of Ethernet120 and come back into
# Ethernet0 (Ethernet0 itself is never mirrored: no loop).
#   qos-hw-20261116-055013  stdout 09f8aa07   qos-hw-20261116-055312  stdout 4e2bf496

== SPAN ingress (INGRESS_MIRROR_SESSION on Ethernet120, monitor Ethernet120), 1000 x 256 B into Ethernet120:
   Ethernet0 IN 0 -> 1000 frames, 260000 B; Ethernet120 OUT 0 -> 1000 (055312). PASS: one full copy per frame.
== ERSPAN ingress (ENHANCED_REMOTE, GRE 0x88be, 10.99.1.1 > 10.99.1.2, TTL 64, TOS 32), same traffic:
   Ethernet0 IN +1000 frames, +310000 B: 310 B per copy = 260 + 50 (Ethernet 14 + IPv4 20 + GRE 8 + ERSPAN II 8)
   (055312). PASS (encapsulated copies; their header bytes not captured: no CPU path for them here).
== Egress SPAN on Ethernet120 for routed frames (1000 x 256 B routed out of Ethernet120):
   no mirror: Ethernet0 IN +1000; egress SPAN: +2000 frames, +440000 B = 1000 x 260 + 1000 x 180 (055013).
   PASS, but egress copies come out truncated to 180 B on the wire (176 B + FCS); the SDK refuses TRUNCATE on
   egress collectors ("Invalid attr check failed", 055312), so it cannot be turned off.
== Egress ERSPAN on Ethernet120: Ethernet0 IN +2000, +490000 B = 1000 x 260 + 1000 x 230 (180 + 50) (055312). PASS.
== Two sessions on one monitor port: the SDK allows one DUP_COPY_DEST_PORT per sysport ("Sysport currently in
   use by DCDP", 055013); the backend now shares it (055312: SPAN then ERSPAN on Ethernet120, both work).
== Egress mirroring of CPU-injected frames (EGRESS_MIRROR_SESSION on Ethernet0, frames from its netdev):
   no copies (Ethernet120 OUT unchanged): CPU-sent frames bypass the egress pipeline.
== ACL mirror action: frontend passes FpRule::mirror_* (mock-tested on the fake); tl_acl does not program it
   yet (ACL area); MirrorArea::collector_set() is there for it. NOT ON THE CHIP.

== sFlow (SAMPLEPACKET on Ethernet120 ingress), 10000 x 256 B at 5000 pps (055312; the same in 054543):
   SAMPLE_RATE 100 -> 156 samples (1 in 64), SAMPLE_RATE 1000 -> 9 (1 in ~1100), disabled -> 0.
   Samples reach the CPU (Ethernet120 netdev) as IPv4/GRE-like frames: outer 0.0.0.0 > 0.0.0.0, TOS 0x08
   (the collector's DSCP 2), TTL 100, GRE proto 0x8818, 314 B for a 256 B frame (the sFlow collector's tags,
   as isai sets them). An earlier run with the rate rounded to 128 gave 131 (1 in 76): the chip's rate is not
   simply 1 in N; SAI's N is passed through as isai does.
   psample / genetlink delivery (what hsflowd needs): NOT AVAILABLE: IFCS 0.12.41 has no netlink API (isai on
   0.16.2 uses ifcs_netlink_create + netlink_trapid_add); the ipd driver has the genetlink family, reachable
   only through its ioctls. Egress sampling: refused (node EGRESS_SFLOW_ENABLE off; isai fails the same way).
