# CS8210 port LEDs: panel checklist (owner replay of the H2-B register walk)

Written 2026-11-26 by H2-B. The walk itself ran without anyone at the rack: every write read back exactly and was restored
(evidence ai_re/devices/cs8210-32x/evidence/rust-h2/01-led-walk.txt); what the LEDs SHOW is the open part, settled here.

## Before you start (about 2 min)
From the workstation (scripts: ai_re/devices/cs8210-32x/evidence/rust-h2/box/):

    cd /home/erin/nepeat/ai_re/devices/cs8210-32x/evidence/rust-h2/box
    tar cf - h2-run.sh led-*.sh led-steps.txt led-r1.regs | sudo ssh root@10.60.2.190 'mkdir -p /run/h2/led && cd /run/h2 && tar xf - && mv led-* led/'
    sudo ssh root@10.60.2.190 /run/h2/led/led-setup.sh        # stops SONiC (the loops flap), starts Credo

The runner uses the Rust libsai /nix/store/jlg9zcvpvsixs9br6jqjf2m74wxgq3r3-sai-teralynx-rs-aarch64-unknown-linux-gnu-0.1.0 (on the box since
2026-11-26, no GC root): if it is gone, rebuild target cs8210-sai-teralynx-rs and `sudo nix copy --to ssh://root@10.60.2.190 <path>`.

Each step is one command on the box (`sudo ssh root@10.60.2.190 '<command>'`), about 50 s:
- ~5 s init, then **"PHASE T ... LOOK NOW for 20 s"**: the test value is on: look at the named cage's LEDs 1-4 (and the panel).
- then re-init with the R1 value restored: **"PHASE R ... LOOK NOW for 10 s"**: the cage must look as at baseline again.
Write down per LED 1-4: dark / colour / blinking (rate), during T and during R.

**Baseline (R1, what R phases should show):** cages 3, 17, 31, 32 linked: LED 1 magenta, LEDs 2-4 dark (cage 31 / 32 only when their link is
up: the output shows "event port 0x10000000000001f oper 1" for cage 31, "...20 oper 1" for cage 32). Cages 1, 2 and the empty ones: dark.
Cage 31 = IB0 PIC3 is inferred: if cage 32 (or another cage) reacts to the W2.31 steps instead of cage 31, note it (the map is then off by one).

## Short list (bold below, ~25 steps, ~25 min): codes, slot -> LED map, colour bits, blink
Run all with one command: `HOLD=20 RHOLD=10 /run/h2/led/led-walk.sh W1c W2.31.b00 W2.31.b01 W2.31.p0003 W2.31.b02 W2.31.b03 W2.31.b04 W2.31.b06 W2.31.p5555 W2.31.paaaa W2.31.pffff W2.3.p0001 W2.3.p0002 W2.3.p0003 W2.3.pffff W3.3.b00 W3.3.b01 W3.3.b02 W4.3.b00 W4.3.b03 W5.3.p0001 W5.3.p0002 W5.3.p0003 W5.fix W6.b07 W6.b10`
(it prints "== <ID>" before each step; the steps run in the file's order, not the order typed).
Everything: `HOLD=20 RHOLD=10 /run/h2/led/led-walk.sh` (92 steps, ~75 min).

## Finish (always)

    sudo ssh root@10.60.2.190 /run/h2/led/led-finish.sh   # pure read: every LED register at R1 (prints nothing but the 2 free-running counters), SONiC back

The W5 steps leave the blink counters frozen non-zero until W5.fix runs: run W5.fix after any W5 step (the short list does).
